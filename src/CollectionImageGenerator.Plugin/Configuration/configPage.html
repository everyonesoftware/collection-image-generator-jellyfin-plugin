Collection Image Generator

Create collection collages from up to four local member posters. No remote images are downloaded.

Allow daily, manual and post-scan generation.
The same collection and members produce the same random order. Collections with fewer than four usable posters repeat them.
Use {name} for the collection name. Text is disabled by default.
Maximum 8,388,608 pixels in total.
Artwork protection

Warning: enabling overwrite can permanently replace custom collection artwork. Keep this off unless you intend to replace your existing images.

Off by default. Normally only missing primaries or unchanged plugin-owned images can be generated. Unreadable images and untrusted ownership records are never overwritten.

Run manually

Save settings, then open scheduled tasks and run Generate collection images. The daily default is 03:00 server-local time; you can change its trigger there.
